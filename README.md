# Forum

A simple static forum app with categories:
- Announcements
- Suggestions
- Polls
- Questions
- Show and Tell
- Other

Open index.html in your browser to use the forum (it stores posts in your browser's localStorage).

Changelog
---------

- 2026-08-17 — v0.2.0: Added authentication pages (login/sign up), categories displayed as online list menu, user profiles tied to posts.
- 2026-08-17 — v0.1.0: Added initial static forum (index.html, styles.css, script.js). Posts are stored in localStorage; supports simple polls and category filtering.

Usage
-----

- Open index.html in a browser.
- Create an account or sign in (credentials stored locally).
- Use the "New Post" form to create posts and polls.
- Click categories in the sidebar to filter posts.
- Vote on polls by clicking the Vote button.

Notes
-----

This repository contains a minimal client-only implementation so you can run it without a server. For a production forum, add a backend and authentication.
